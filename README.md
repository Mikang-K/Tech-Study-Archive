# Technical Study Archive

기술의 배경과 동작 원리, 근거 자료와 실습 결과를 기록하는 개인 학습 아카이브입니다. 세미나에서는 그때까지 정리한 내용을 선별해 공유합니다.

첫 학습 시리즈는 **GPU Scheduling & Orchestration**입니다. 전체 범위는 4개 Phase와 8개 Chapter이며, 상세 계획은 [학습 로드맵](roadmap.qmd)에 있습니다.

## 로컬에서 확인하기

[Quarto](https://quarto.org/)가 설치된 환경에서 저장소 루트에서 실행합니다.

```powershell
quarto preview # 로컬 미리보기
quarto render  # 게시용 HTML 생성
```

결과물은 `_site/`에 생성됩니다. `main`에 push하면 기존 GitHub Actions가 사이트를 렌더링하고 GitHub Pages로 배포합니다.

## 파일 구성

| 위치 | 용도 |
|---|---|
| `index.qmd` | 아카이브 소개와 현재 학습 주제 |
| `roadmap.qmd` | 첫 시리즈의 전체 계획과 학습 방법 |
| `topics/` | 실제 공부하면서 작성할 학습 문서 |
| `seminars/` | 관련 학습 문서를 연결할 발표 기록과 PPTX |
| `assets/` | 구성도와 이미지 |
| `references.bib` | 학습하며 추가할 참고문헌 |
| `_quarto.yml`, `styles.css` | 사이트 탐색과 공통 디자인 |

빈 폴더는 Git에 저장되지 않습니다. 필요한 문서를 작성할 때 해당 폴더를 사용합니다. 프로젝트는 `.qmd` 파일을 렌더링하며, README와 작업 계획은 사이트 페이지에 포함하지 않습니다.

## 학습 문서 작성

공부하지 않은 내용을 미리 완성된 문서로 채우지 않습니다. 처음에는 챕터 단위로 시작하고 내용이 커질 때 나눕니다. 새 문서는 `topics/` 아래 `.qmd`로 작성하고, `_quarto.yml`의 `website.sidebar.contents`에 링크를 추가합니다.

기본 흐름은 다음과 같습니다. 모든 글에 모든 항목을 채울 필요는 없습니다.

1. 이번에 이해하려는 질문과 다루는 범위
2. 현재까지 이해한 내용
3. 구조와 동작 과정
4. 근거 자료와 실습 기록
5. 남은 질문과 한계
6. 정리와 다음 질문

- 제목은 YAML의 `title`에 작성합니다. 상태는 본문에 `학습 중`, `정리 중`, `1차 정리`로 표시합니다.
- 자료에서 확인한 사실, 직접 검증한 결과, 개인적인 해석을 구분합니다.
- 실험에는 환경과 버전, 절차, 결과와 한계를 남깁니다. 직접 검증하지 못한 부분도 명시합니다.
- 문서를 게시하면 홈의 학습 기록에 제목, 핵심 질문, 실제 갱신일과 링크를 추가합니다. 로드맵의 현재 위치도 함께 갱신합니다.

## 발표자료 관리

학습 문서를 원본으로 두고 발표 내용은 별도로 선별합니다. 발표 형식은 PowerPoint에서 편집하는 PPTX입니다. 발표 기록에는 발표일, 실제 발표 범위, 관련 학습 문서와 PPTX 링크를 남깁니다.

Quarto로 PPTX 초안을 만들 경우 발표용 QMD를 별도로 작성하고 다음처럼 출력할 수 있습니다.

```powershell
quarto render seminars/발표.qmd --to pptx
```

PowerPoint에서 직접 편집한 최종본은 재생성하는 초안과 다른 이름으로 보관합니다. 웹 도표가 PowerPoint의 편집 가능한 도형으로 변환되는지는 별도로 확인해야 합니다.
